Сіздің тапсырмаларыңыз.
Өз қарқыныңыз.

Пайдаланушы ID нөмірін таңдаңыз. Барлық тапсырмалар үшін 0 енгізіңіз.

ID арқылы ашық деректер сүзіледі. Бұл құпиясөз немесе API кілті емес.

ID енгізіп, «Тапсырмаларды жүктеу» батырмасын басыңыз.

    Тапсырмалар жоқ. Алғашқы тапсырманы қосыңыз!

    Оқу API қызметі өзгерістерді серверде сақтамайды. Өзгерістер осы браузерде әр пайдаланушы үшін жеке сақталады. «Жергілікті» тапсырмалар браузерде өңделеді. Барлық тапсырмалар режимінде жаңа тапсырма қосу үшін нақты пайдаланушы ID нөмірін таңдаңыз. API тапсырмаларының бастапқы мәтіні түпнұсқа тілінде көрсетіледі.
