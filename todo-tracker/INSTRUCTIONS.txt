Task Desk — отдельный учебный проект HTML/CSS/JavaScript

Запуск: откройте эту папку в VS Code, затем index.html через Live Server.
Нужен доступ к интернету. Начальный ID 152 имеет задачи в текущем DummyJSON.

index.html — интерфейс; styles.css — оформление; app.js — запросы и события.

READ: GET /todos/user/{id}?limit=0
CREATE: POST /todos/add с todo, completed, userId
UPDATE: PATCH /todos/{id} для исходных задач API
DELETE: DELETE /todos/{id} для исходных задач API

DummyJSON — учебный сервис: сервер не сохраняет изменения.
Приложение сохраняет снимок задач в localStorage отдельно для каждого userId.
При повторной загрузке сначала выполняется GET, затем используется сохранённый
снимок данного пользователя, если он есть. Это не синхронизация с другими устройствами.

Созданные через POST задачи отсутствуют на сервере: их последующее изменение
и удаление локальные и не отправляют запрос на несуществующий серверный ID.
У новых задач собственный уникальный key: повторяющиеся ID DummyJSON не мешают.

userId — фильтр публичного набора данных, а не авторизация и не секретный ключ.
Для настоящих личных задач с серверным сохранением нужен другой backend.

Проверка: загрузить пользователя, добавить две задачи, изменить текст,
переключить completed (оқылды / оқылды емес), применить фильтр, удалить задачу.
Перейти на другой ID и обратно: списки не смешиваются.
Перезагрузить страницу и загрузить тот же ID: локальные изменения сохраняются.
